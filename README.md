## Features

- **Digital Bilty / Lorry Receipt (LR) maker** — professional LR print with own letterhead
- **Multi-page GST billing** — 50+ trips ka ek bill, Page 2+ par compact continuation header (CA-audit safe)
- **Market hired-truck khata** — supplier advance, diesel slips, shortage/commission + Section 194C TDS auto-calculation, Settlement Voucher print
- **Diesel & mileage tracking** — pump-wise slip entries, automatic KM/Litre mileage, low-average/theft red alerts
- **Bank statement import** — SBI, HDFC, ICICI, PNB Excel/PDF statement se auto-reconciliation (freight collection, driver advance, pump cheques)
- **Excel bulk import** — purani sheets se hazaron trips/trucks seconds me
- **Custom branding** — apna logo, GSTIN, terms & UPI QR code bills par
- **Google Drive Cloud Vault** — har 30 minute + app band hote waqt automatic backup, 1-click restore naye PC par
- **Offline-first** — internet band ho toh bhi sab kuch chalta hai (local SQLite)
- **Auto-updater** — naye updates free, automatic
